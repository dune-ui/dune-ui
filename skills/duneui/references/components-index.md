# DuneUI component catalog

| Component | Tags | Summary |
|-----------|------|---------|
| [Accordion](components/accordion.md) | `<dui-accordion>`, `<dui-accordion-item>`, `<dui-accordion-item-content>`, … | A vertically stacked set of collapsible items, each of which can be expanded to reveal its content. |
| [Alert](components/alert.md) | `<dui-alert>`, `<dui-alert-action>`, `<dui-alert-description>`, … | A callout that displays a short, important message to the user, optionally with an icon, title, and description. |
| [AlertDialog](components/alert-dialog.md) | `<dui-alert-dialog>`, `<dui-alert-dialog-action>`, `<dui-alert-dialog-cancel>`, … | A modal dialog that interrupts the user to confirm an important action, rendered over a native `<dialog>` element. |
| [Avatar](components/avatar.md) | `<dui-avatar>`, `<dui-avatar-badge>`, `<dui-avatar-group>`, … | Displays a user's image, falling back to initials or a name-derived monogram when no image is available. |
| [Badge](components/badge.md) | `<dui-badge>` | A small label used to highlight status, counts, or categories. |
| [Breadcrumb](components/breadcrumb.md) | `<dui-breadcrumb>`, `<dui-breadcrumb-ellipsis>`, `<dui-breadcrumb-item>`, … | A breadcrumb navigation trail, rendered as a `<nav>`; shows the path to the current page. |
| [Button](components/button.md) | `<dui-button>`, `<dui-linkbutton>` | Renders a button element for triggering actions. |
| [ButtonGroup](components/button-group.md) | `<dui-button-group>`, `<dui-button-group-separator>`, `<dui-button-group-text>` | Groups related buttons together as a single visual unit. |
| [Card](components/card.md) | `<dui-card>`, `<dui-card-action>`, `<dui-card-content>`, … | A flexible container that groups related content, composed of a header, title, description, content, footer, and action subcomponents. |
| [Collapsible](components/collapsible.md) | `<dui-collapsible>` | A container whose content can be expanded or collapsed. |
| [Dialog](components/dialog.md) | `<dui-dialog>`, `<dui-dialog-description>`, `<dui-dialog-footer>`, … | A modal window overlaid on the page, rendered over a native `<dialog>` element. |
| [DropdownMenu](components/dropdown-menu.md) | `<dui-dropdown-menu>`, `<dui-dropdown-menu-checkbox-item>`, `<dui-dropdown-menu-content>`, … | The root of a dropdown menu, pairing a trigger with its content and generating the shared id that links them. |
| [Empty](components/empty.md) | `<dui-empty>`, `<dui-empty-content>`, `<dui-empty-description>`, … | An empty-state container that communicates the absence of content, composed of a header, media, title, description, and content subcomponents. |
| [Field](components/field.md) | `<dui-field>`, `<dui-field-content>`, `<dui-field-description>`, … | Wraps a form control together with its label, description, and error message, arranging them according to the chosen orientation. |
| [Icon](components/icon.md) | `<dui-icon>` | Renders an SVG icon from the active icon pack by name. |
| [Input](components/input.md) | `<dui-input>` | A form input. |
| [InputGroup](components/input-group.md) | `<dui-input-group>`, `<dui-input-group-addon>`, `<dui-input-group-button>`, … | A container that groups an input with add-ons, buttons, or text so they render as a single combined field. |
| [InputOtp](components/input-otp.md) | `<dui-input-otp>`, `<dui-input-otp-group>`, `<dui-input-otp-separator>`, … | A segmented one-time-code input. |
| [Item](components/item.md) | `<dui-item>`, `<dui-item-actions>`, `<dui-item-content>`, … | A flexible row for presenting content, combining media, a title, description, and actions. |
| [Kbd](components/kbd.md) | `<dui-kbd>`, `<dui-kbd-group>` | Displays a single keyboard key or keystroke. |
| [Label](components/label.md) | `<dui-label>` | A caption for a form control, optionally bound to a model expression via `asp-for`. |
| [Layout](components/layout.md) | `<dui-group>`, `<dui-container>`, `<dui-stack>` | A horizontal flex layout that arranges its children in a row, with configurable alignment, spacing, and justification. |
| [Pagination](components/pagination.md) | `<dui-pagination>`, `<dui-pagination-content>`, `<dui-pagination-ellipsis>`, … | Navigation for moving between pages of content. |
| [Popover](components/popover.md) | `<dui-popover>`, `<dui-popover-description>`, `<dui-popover-header>`, … | A floating panel of rich content anchored to a trigger element, rendered as a native popover. |
| [Progress](components/progress.md) | `<dui-progress>`, `<dui-progress-label>`, `<dui-progress-value>` | A progress bar that visualizes the completion of a task as a filled track. |
| [Select](components/select.md) | `<dui-select>` | A styled dropdown for choosing a single option, wrapping a native `<select>` element with a custom chevron icon. |
| [Separator](components/separator.md) | `<dui-separator>` | A thin dividing line between sections of content, rendered as a `<div>` with `role="separator"`. |
| [Sheet](components/sheet.md) | `<dui-sheet>`, `<dui-sheet-description>`, `<dui-sheet-footer>`, … | A panel that slides in from an edge of the screen, rendered over a native `<dialog>` element. |
| [Sidebar](components/sidebar.md) | `<dui-sidebar>`, `<dui-sidebar-content>`, `<dui-sidebar-footer>`, … | The sidebar panel itself, hosting its header, content, and footer. |
| [Skeleton](components/skeleton.md) | `<dui-skeleton>` | A placeholder that shows an animated pulsing shape while content is loading. |
| [Slider](components/slider.md) | `<dui-slider>` | An input for selecting a numeric value, or a range of values, by dragging one or more thumbs along a track. |
| [Spinner](components/spinner.md) | `<dui-spinner>` | An animated spinning icon that indicates a loading or busy state. |
| [Switch](components/switch.md) | `<dui-switch>` | A toggle control that switches between on and off states. |
| [Table](components/table.md) | `<dui-table>`, `<dui-table-body>`, `<dui-table-caption>`, … | A responsive data table, rendered as a `<table>` inside a scrollable container. |
| [Tabs](components/tabs.md) | `<dui-tab-link>`, `<dui-tab-list>` | A single tab within a `<dui-tab-list>`, rendered as a link to its target view. |
| [Textarea](components/textarea.md) | `<dui-textarea>` | A styled multi-line text input that grows with its content. |
| [Toggle](components/toggle.md) | `<dui-toggle>` | Renders a two-state button that can be toggled on or off. |
| [ToggleGroup](components/toggle-group.md) | `<dui-toggle-group>`, `<dui-toggle-group-item>` | Groups a set of toggle items into a single-select or multi-select control. |
| [Tooltip](components/tooltip.md) | `<dui-tooltip>` | A small floating label that appears when the user hovers or focuses a trigger element, rendered as a native hint popover. |
